# Авторские профили Ghost и финальные блоки русских страниц

Состояние production зафиксировано 15 сентября 2026 года.

## Авторские профили

| Язык материала | Профиль автора | Роль в Ghost |
|---|---|---|
| Русский | `Пётр Миленин` | основной административный профиль |
| Английский | `Peter Milenin` | `Author` |

Адрес приглашения и другие персональные данные в публичном репозитории не
хранятся. Они доступны владельцу в Ghost Admin → Settings → Staff.

## Английские материалы

Профиль `Peter Milenin` назначен единственным автором:

- 18 опубликованных английских статей с internal tag `English`;
- страницы `After Login`, `Project Map`, `About the Project`,
  `About the Author`, `Audio Essays`, `Contact`.

Двойных назначений с русским профилем у этих материалов после проверки нет.

Рабочее правило для новых публикаций:

1. открыть настройки статьи или страницы;
2. для русской версии выбрать `Пётр Миленин`;
3. для английской версии выбрать `Peter Milenin`;
4. перед публикацией убедиться, что остался только один нужный автор.

Публиковать можно из основного административного аккаунта: автор материала и
аккаунт, под которым выполнен вход в Ghost Admin, не обязаны совпадать.

## Русские страницы

Новый финальный блок установлен на пяти страницах:

| Страница | Slug |
|---|---|
| Карта проекта | `/karta-proekta/` |
| О проекте | `/o-proekte/` |
| Об авторе | `/ob-avtorie/` |
| Аудиотека | `/audiotieka/` |
| Контакты | `/kontakty/` |

Финальная последовательность на каждой странице:

1. блок подписки;
2. блок «Разговор продолжается в Гостиной»;
3. контакт автора.

Кнопка `Войти в Гостиную` ведёт на `https://milenin.pro/gostinaya/`.
Публичное отображение всех пяти страниц проверено после сохранения.
Английские страницы в рамках этой операции не изменялись.

## Восстановление и проверка

Это документирование состояния, а не резервная копия содержимого Ghost.
Назначения авторов и карточки страниц находятся в базе Ghost. Для точного
восстановления использовать согласованный дамп Ghost/MariaDB и архив Ghost
content volume, затем проверить:

- в Staff присутствуют оба профиля;
- каждая английская публикация имеет только автора `Peter Milenin`;
- пять русских страниц заканчиваются тремя указанными блоками;
- ссылка кнопки открывает `/gostinaya/`;
- английские страницы сохранили прежнее содержимое.
