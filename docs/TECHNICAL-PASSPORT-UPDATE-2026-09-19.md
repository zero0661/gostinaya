## 2. Что изменилось в Гостиной

### 2.1. Один интерфейс — два языка

Гостиная переведена с модели «русский текст + серая английская копия» на настоящий выбор языка интерфейса.

Правила:

- пользователь видит только выбранный язык интерфейса;
- активный язык отображается обычным основным цветом, не как вторичный перевод;
- переключатель `RU / EN` доступен в публичной и авторизованной части;
- `<html lang>` меняется вместе с интерфейсом;
- язык аккаунта хранится в профиле как `ru` или `en`;
- сохранённый `Preferred language / Предпочитаемый язык` используется при следующем входе;
- пользовательские сообщения и комментарии не переводятся автоматически и сохраняют язык автора.

Публичные и авторизованные шаблоны используют `data-lang="ru"` / `data-lang="en"` и общую клиентскую логику переключения.

### 2.2. Профиль и язык аккаунта

В профиле локализованы подписи, уведомления, сведения об аккаунте и значения роли/языка.

Проверено в production:

1. пользователь выбирает `English` или `Русский` в поле предпочитаемого языка;
2. нажимает сохранение профиля;
3. выходит из аккаунта;
4. после следующего входа Гостиная открывается на сохранённом языке.

Само переключение верхнего `RU / EN` без сохранения профиля не должно подменять сохранённое предпочтение аккаунта.

### 2.3. Общая дискуссия для RU/EN пары статьи

Сохраняется принцип «две языковые оболочки — одно обсуждение».

Для связанной пары статей:

- RU и EN публикации ведут к одному `topicId`;
- в RU-интерфейсе показывается русская статья;
- в EN-интерфейсе показывается английская статья;
- сообщения в теме общие;
- комментарии не переводятся;
- для старых одиночных публикаций действует безопасный fallback, чтобы обсуждение не исчезало при несовпадении языка интерфейса.

На странице обсуждения заголовок, изображение и ссылка на исходную статью выбираются по активной языковой версии, если она существует.

### 2.4. Новости проекта стали двуязычными

Новые новости проекта создаются как одна сущность с двумя версиями:

- `RU title` + `RU text`;
- `EN title` + `EN text`;
- одна общая дискуссия.

В интерфейсе участник видит только выбранную языковую версию.

Для старых односторонних записей сохранён fallback. Если английского текста у старой новости нет, EN-интерфейс показывает нейтральное сообщение `English version not available yet`, а не русский текст под английской оболочкой.

Добавлена миграция `database/migrate-bilingual-news.js`.

### 2.5. Уведомления

Страница уведомлений локализована полностью на уровне интерфейса:

- тип события;
- статус прочтения;
- подписи действия;
- системные фразы;
- кнопки перехода;
- локальное форматирование даты.

Для уведомлений по связанным RU/EN статьям устранён показ заголовка статьи на чужом языке, когда у пары есть локализованная версия.

Актуальный commit этой правки: `0dab6caa1f079250fe4915ee20a43732c5be2a98` — `Avoid cross-language article titles in notifications`.

## 3. Мобильная версия

После проверки на iPhone авторизованная Гостиная получила отдельный mobile-pass.

### 3.1. Навигация

При ширине до 700 px:

- постоянная боковая колонка скрывается;
- появляется кнопка `☰ Меню / Menu`;
- меню раскрывает ту же навигацию без дублирования маршрутов;
- закрывается после перехода по ссылке и по `Escape`;
- touch target кнопок не меньше примерно 44–46 px.

### 3.2. Баннер

На мобильном:

- баннер сокращён до изображения;
- декоративный заголовок и цитата скрыты;
- высота изображения фиксирована примерно на 210 px;
- используется `object-fit: cover`.

### 3.3. Контент

Мобильные правки охватывают:

- Project News;
- Community Topics;
- Members;
- Profile;

## 4. Hall

Hall теперь локализован и использует выбранный язык интерфейса.

Для карточки последней статьи заголовок берётся из актуальной RU/EN пары Ghost, а не из общего заголовка темы обсуждения. Это устраняет показ русского заголовка в английском Hall и наоборот.

Карточки Hall адаптированы для узкого экрана: уменьшены внутренние отступы, заголовки и статистика не требуют горизонтального скролла.

## 6. Production-порядок обновления

Рабочая последовательность, использованная и проверенная 19 сентября 2026:

```bash
cd /root/gostinaya
git pull --ff-only origin feature/article-subscriptions
npm test
pm2 restart gostinaya
curl -i http://127.0.0.1:3001/health
```

Ожидаемый health-check:

```text
HTTP/1.1 200 OK
...
Gostinaya is alive
```

PM2 должен показывать процесс `gostinaya` в состоянии `online`.

## 7. Важное состояние сервера

В `/root/gostinaya` присутствуют локальные untracked backup/legacy-файлы и каталоги, в том числе резервные копии `.env`, SQLite, старых CSS и GhostApiService. Они не должны случайно попадать в Git.

Перед любым массовым `git add .` сначала выполнять:

```bash
git status --short
git status --short --untracked-files=no
```

В Git коммитить только явно выбранные файлы проекта.
