Техническая часть:
- обязательное boolean consent и точная версия, иначе HTTP 400 до обращения к Ghost/SMTP;
- журнал SQLite email/language/version/accepted_at/id; подтверждение по почте связывается с той же записью;
- ошибка записи согласия прекращает запрос;
- прежние токены продолжают подтверждать ранее запрошенные подписки без создания фиктивного согласия;
- отдельный capture обработчик заменяет поведение старых HTML-форм без перезаписи карточек CMS; required checkbox исходно не отмечен;
- IP, user-agent и дополнительные идентификаторы не собираются журналом;
- новое согласие не подставляется существующим подписчикам задним числом.

- 146 тестов проходят, включая отзыв до синхронизации с Ghost, отказ отправки при недоступном журнале и безопасную очистку.
- В отдельной SQLite проверены запись и подтверждение согласия, идемпотентность миграции, запрет доставки после отзыва и повторная подписка только после нового подтверждения.
